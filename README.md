# EC665 Tiger - HeliSim

## Requires

| mod | why |
|---|---|
| BradMick's HeliSim 1.3.0.0 or later | the flight model this pack drives; 1.3.0.0 is what reads `damageRole`, so a rotor shot off stops |
| BW-Mod | the Tiger itself (`bwa3_tiger`) |
| CBA_A3 | HeliSim's dependency |

Load all three in game. This pack loads after HeliSim and after BW-Mod's Tiger.
